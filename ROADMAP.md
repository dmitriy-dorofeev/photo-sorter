# Roadmap: как использовать план

Этот файл — твой путеводитель. Не пытайся проглотить всё сразу. Открывай только текущий шаг, делай, закрывай. Когда застрянешь — пиши мне.

---

## Шаг 0. Установка окружения (сделай сегодня/завтра)

```bash
# 1. Установи Go
brew install go

# 2. Установи exiftool (понадобится для видео)
brew install exiftool

# 3. Проверь, что всё работает
go version
exiftool -ver

# 4. Зайди в папку проекта и собери
cd photo-sorter
go build -o photo-sorter cmd/main.go
./photo-sorter
```

**Результат:** у тебя есть рабочее окружение и собирающийся проект с готовым TUI-скелетом.

## ✅ Шаг 1. TUI-скелет (готово)

Приложение уже имеет полноценный интерфейс на `bubbletea`:

- 6 экранов: Источник → Цель → Настройки → Сканирование → Предпросмотр → Копирование
- Навигация стрелками `←/→`, браузеры папок с `Enter/Backspace/Space`
- Экран настроек с пресетами шаблонов и булевыми переключателями

**Что осталось:** подключить реальные internal-пакеты к экранам сканирования, предпросмотра и копирования.

## Шаг 2. Доделать internal-пакеты (1–1.5 недели)

### 2.1. `dateresolver` — движок дат

Это самое важное. Приложение либо правильно определяет дату, либо бесполезно.

- [x] Реализовать чтение EXIF из `.jpg`/`.jpeg` через `github.com/rwcarlsen/goexif/exif`.
- [x] Написать парсеры имён файлов для всех паттернов из `PLAN.md`.
- [x] Реализовать приоритет: EXIF → имя файла → `mtime` → `unsorted/`.
- [x] Написать unit-тесты для каждого паттерна и edge cases (пустая строка, `DSC_1234.jpg`).

**Фокус:** модуль `internal/dateresolver/`. Остальное пока не трогай.

### 2.2. `deduper` — поиск дубликатов

- [x] Группировка по размеру.
- [x] Сравнение по `xxhash` внутри групп одинакового размера.
- [x] Учёт Live Photos (`.HEIC` + `.MOV` не считаются дублями друг друга).
- [x] Unit-тесты.

**Реализовано** в `internal/deduper/`:
- `hasher.go` — потоковое хеширование файлов через `github.com/cespare/xxhash/v2`
- `deduper.go` — двухуровневая дедупликация (размер → хеш) с фильтрацией Live Photos
- `deduper_test.go` — тесты на дубли, разные файлы одинакового размера, Live Photos

### 2.3. `scanner`, `sorter`, `copier`

- [x] Доработать `scanner` — фильтрация по расширениям, параллельный обход.
- [x] Доработать `sorter` — обработка коллизий имён (`_1`, `_2`), поддержка Live Photos.
- [x] Доработать `copier` — прогресс, отмена, проверка свободного места.

**Реализовано:**
- `scanner` — `New(sources, exts...)` с whitelist и параллельным `errgroup`
- `sorter` — `Skip` для дубликатов, разрешение коллизий `_1`/`_2`, Live Photos fallback для `.MOV`
- `copier` — `context.Context`, progress callback, `Stats`, проверка диска через `unix.Statfs`, обработка внешних коллизий по хешу

## Правила дисциплины

1. **Коммить в Git после каждой сессии.** Даже если код неидеален.
2. **Не работай с оригиналами фотографий сына.** Всегда тестируй на `testdata/` или копии.
3. **Всегда начинай с dry-run.**
4. **Unknown date → `unsorted/`**, никогда не теряй файл.
5. **Если застрял больше чем на 30 минут** — сразу пиши мне. Не бейся головой о стену.

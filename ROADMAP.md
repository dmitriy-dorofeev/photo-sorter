# Roadmap: как использовать план

Этот файл — твой путеводитель. Не пытайся проглотить всё сразу. Открывай только текущий шаг, делай, закрывай. Когда застрянешь — пиши мне.

---

## Шаг 0. Установка окружения (сделай сегодня/завтра)

```bash
# 1. Установи Go
brew install go

# 2. Установи exiftool (понадобится для видео)
brew install exiftool

# 3. Проверь, что всё работает
go version
exiftool -ver

# 4. Зайди в папку проекта и попробуй собрать
cd photo-sorter
go build -o photo-sorter cmd/main.go
./photo-sorter
```

**Результат:** у тебя есть рабочее окружение и собирающийся (хоть и пустой) проект.

## Шаг 1. Неделя 0 — базовый Go (1 неделя)

Цель: уметь писать простые программы на Go и не паниковать от синтаксиса.

- [ ] Пройти [A Tour of Go](https://go.dev/tour/welcome/1) (пакеты, структуры, интерфейсы, горутины, каналы).
- [ ] Написать мини-программу: рекурсивно обойди папку `testdata/` и напечатай имена всех файлов.
- [ ] Попробовать запустить `go test` в папке `internal/scanner/` (пока там нет тестов — просто убедись, что команда работает).
- [ ] Прочитать [примеры bubbletea](https://github.com/charmbracelet/bubbletea/tree/master/examples) (достаточно посмотреть `simple` и `list`).

**Если застрял:** присылай мне код или ошибку — я объясню, что не так.

## Шаг 2. Неделя 1 — «движок дат» (1–1.5 недели)

Это самое важное. Приложение либо правильно определяет дату, либо бесполезно.

- [ ] Реализовать чтение EXIF из `.jpg`/`.jpeg` через `github.com/rwcarlsen/goexif/exif`.
- [ ] Написать парсеры имён файлов для всех паттернов из `PLAN.md`.
- [ ] Реализовать приоритет: EXIF → имя файла → `mtime` → `unsorted/`.
- [ ] Написать unit-тесты для каждого паттерна и edge cases (пустая строка, `DSC_1234.jpg`).

**Фокус:** модуль `internal/dateresolver/`. Остальное пока не трогай.

- [ ] Доработать `internal/scanner/` — параллельный обход нескольких папок.
- [ ] Реализовать `internal/deduper/`:

**Результат:** программа работает в консоли и выдаёт текстовый отчёт.

## Шаг 4. Неделя 3 — TUI интерфейс (1.5–2 недели)

Это самое сложное для новичка. Не торопись.

- [ ] Подключить `github.com/charmbracelet/bubbletea`.
- [ ] Сделать экран выбора папок (источники + цель).
- [ ] Сделать экран настроек (шаблон папок, опция Live Photos).
- [ ] Сделать экран сканирования с прогресс-баром.
- [ ] Сделать экран предпросмотра (dry-run) — дерево папок, список дублей, `unsorted`.

**Если трудно:** попроси меня написать базовый скелет TUI, а ты будешь его наполнять.

## Как я могу помогать тебе дальше

Обращайся в любой момент. Вот типичные запросы:

- **«Объясни концепцию»** — например, интерфейсы в Go, `filepath.WalkDir`, `errgroup`.
- **«Напиши код для модуля X»** — я напишу полную реализацию, ты разберёшь её.
- **«Почему падает тест?»** — скинь текст ошибки, я подскажу.
- **«Проверь мой код»** — пришли файл или Pull Request, сделаю code review.
- **«Давай сделаем вместе»** — разрабатываем пошагово прямо здесь, в чате.

## Правила дисциплины

1. **Коммить в Git после каждой сессии.** Даже если код неидеален.
2. **Не работай с оригиналами фотографий сына.** Всегда тестируй на `testdata/` или копии.
3. **Всегда начинай с `--dry-run`.**
4. **Unknown date → `unsorted/`**, никогда не теряй файл.
5. **Если застрял больше чем на 30 минут** — сразу пиши мне. Не бейся головой о стену.

**A.** Самостоятельно пройти A Tour of Go и попробовать запустить `scanner.Scan()` на тестовой папке.

**Рекомендация:** если хочешь быстрее увидеть результат — выбирай **C**. Если хочешь глубже понять Go — выбирай **A** или **B**.

# photo-sorter

Консольное TUI-приложение на Go для организации фотографий и видео с разных устройств.

## Что делает

- Сканирует исходные папки (iPhone, Android, компьютер и т.д.)
- Находит и пропускает дубликаты
- Определяет дату съёмки по EXIF, имени файла или `mtime`
- Копирует файлы в целевую папку по структуре `YYYY/MM/DD/`

## Установка Go

Перед сборкой проекта необходимо установить Go 1.24+.

### macOS (рекомендуемый способ)

```bash
# Через Homebrew
brew install go

# Проверь версию
go version
```

### Альтернативный способ (официальный установщик)

1. Скачай установщик для macOS с [go.dev/dl](https://go.dev/dl/)
2. Запусти `.pkg` и следуй инструкциям.
3. Перезапусти терминал и проверь: `go version`

## Установка приложения

Требования:
- Go 1.24+
- `exiftool` (опционально, но рекомендуется для видео)

```bash
git clone <repo>
cd photo-sorter
go build -o photo-sorter cmd/main.go
```

## Запуск

Приложение запускается в интерактивном TUI-режиме:

```bash
./photo-sorter
```

### Экраны TUI

1. **Выбор источника** — браузер папок. Выберите папку с фотографиями (`Пробел`), затем `→`.
2. **Выбор цели** — выберите папку, куда скопировать отсортированные файлы.
3. **Настройки** — шаблон папок (`YYYY/MM/DD` и др.), опции Live Photos, видео, dry-run.
4. **Сканирование** — прогресс обработки файлов.
5. **Предпросмотр** — дерево целевой структуры, список дублей и файлов без даты.
6. **Копирование** — прогресс копирования файлов.

**Навигация:** `↑/↓` — курсор, `Enter` — открыть/подтвердить, `Backspace` — вверх по папкам, `←/→` — назад/вперёд по экранам, `Esc` — выход.

### CLI-режим (в разработке)

В будущем будет доступен запуск из терминала с флагами:
```bash
./photo-sorter --source ~/Photos/iPhone --source ~/Photos/Android --target /Volumes/ExternalDisk --dry-run
```

## Безопасность

- Приложение **только копирует**, никогда не перемещает.
- Всегда используй **dry-run** перед реальным запуском (включено по умолчанию в настройках).
- Файлы без распознаваемой даты попадают в папку `unsorted/`.

# План разработки photo-sorter

Консольное TUI-приложение на Go для организации фотографий и видео с разных устройств.

## Описание

Основные возможности:
- Сканирование исходных папок
- Определение даты съёмки по приоритету: EXIF/видео-метаданные → парсинг имени файла → mtime
- Поиск и пропуск дубликатов
- Сортировка по папкам по датам (`YYYY/MM/DD/`)
- Поддержка Live Photos (`.HEIC` + `.MOV`)
- Консольный TUI на `bubbletea` с прогрессом, предпросмотром и режимом `dry-run`
- CLI-режим с флагами для автоматизации

## Реализовано

### TUI-скелет (`tui/`)

Полноценная навигация по 6 экранам со стрелками `←` / `→` (назад / вперёд):

1. **Выбор источника** — браузер папок. `↑/↓` — курсор, `Enter` — открыть папку, `Backspace` — вверх, `Пробел` — выбрать источник, `→` — далее.
2. **Выбор цели** — аналогичный браузер. `←` — назад, `→` — далее.
3. **Настройки** — шаблон папок (пресеты + свой формат), булевы переключатели (Live Photos, видео, dry-run). `↑/↓` — курсор, `Enter/Пробел` — изменить, `←/→` — навигация.
4. **Сканирование** — реальный прогресс обработки файлов (scanner → deduper → sorter).
5. **Предпросмотр (dry-run)** — дерево целевой структуры, список дублей, unsorted.
6. **Копирование** — асинхронное копирование с progress callback, отменой и логированием.

### Internal-пакеты

- **`scanner`** — рекурсивный `filepath.WalkDir` с фильтрацией расширений и параллельным `errgroup`.
- **`dateresolver`** — полный движок дат:
  - `exif.go` — чтение EXIF через `goexif` (`DateTimeOriginal`)
  - `video.go` — чтение видео-метаданных через `exiftool` (`DateTimeOriginal` → `CreateDate` → `MediaCreateDate`)
  - `filename.go` — реестр из 8 парсеров имени файла
  - `dateresolver.go` — приоритет: EXIF → видео → имя → `mtime` → `unsorted`
- **`deduper`** — двухуровневый детектор дубликатов (размер → `xxhash`). Фильтрация Live Photos.
- **`sorter`** — построение дерева с `Skip` для дублей, разрешением коллизий `_1`/`_2`, Live Photos fallback для `.MOV`.
- **`copier`** — копирование с `context.Context`, progress callback, `Stats`, проверкой диска через `unix.Statfs`, обработкой внешних коллизий по хешу, ранним прерыванием при потере диска.
- **`logger`** — запись в файл с timestamp.
- **`runner`** — единый pipeline `Run(cfg Config)` для TUI и CLI (scan → dedup → sort).

### CLI

Полноценный CLI с флагами:
```bash
go run . --source ~/Photos/iPhone --source ~/Photos/Android --target /Volumes/ExternalDisk --dry-run
```

Поддерживает текстовый и JSON-отчёт (`--format=text|json`).

## Алгоритмы

### Приоритет определения даты

Для каждого файла:
1. **EXIF / видео-метаданные** (`DateTimeOriginal`, `CreateDate`, `MediaCreateDate`)
2. **Парсинг имени файла** по известным паттернам
3. **`mtime`** (fallback, опционально)
4. Если ничего не подошло → `unsorted/`

### Парсеры имён файлов

- `Screenshot YYYY-MM-DD at HH.MM.SS`
- `YYYY-MM-DD HH.MM.SS`
- `IMG_YYYYMMDD_HHMMSS`
- `VID_YYYYMMDD_HHMMSS`
- `PXL_YYYYMMDD_HHMMSSmmm`
- `signal-YYYY-MM-DD-HH-MM-SS`
- `IMG-YYYYMMDD-WA####`
- `YYYYYMMDD_HHMMSS`

### Дедупликация

- **Быстрая:** группировка по размеру.
- **Точная:** `xxhash` внутри групп одинакового размера.
- Дедупликация работает **глобально** по всем исходным папкам.
- Live Photos (`.HEIC` + `.MOV` с одним basename) не считаются дублями друг друга.

### Обработка коллизий

Если в целевой папке файл уже существует:
- Сравниваем по хешу (`xxhash`).
- Хеши совпадают → пропускаем (дубль).
- Хеши разные → суффикс: `IMG_1234_1.jpg`, `IMG_1234_2.jpg`.

### Live Photos

iPhone создаёт пары `IMG_1234.HEIC` + `IMG_1234.MOV`. Sorter распознаёт их по базовому имени и сортирует рядом.

### Обработка ошибок

- Недостаточно места на диске — проверка перед копированием.
- Потеря диска во время копирования — прерывание после 3 ошибок подряд, если targetRoot недоступен.
- Файлы без прав на чтения — пропуск, запись в лог.

### Unit-тесты

- `deduper_test.go` — дубли, разные файлы с одинаковыми именами, Live Photos.
- `sorter_test.go` — построение дерева, коллизии, Live Photos.
- `copier_test.go` — копирование, обработка ошибок, прерывание.
- `video_test.go` — парсинг дат из exiftool.

### Интеграционные тесты

- `runner/runner_test.go` — pipeline scan → dedup → sort.

### Тестовые данные

`testdata/e2e/source/` содержит реалистичные фейковые файлы:
- `2023/` — 12 файлов (iPhone, Android, Screenshot, дубли, без даты, видео, Live Photos)
- `2024/` — 9 файлов (все паттерны имён)

## Правила безопасности

1. **Копируй, не перемещай.**
2. **Всегда dry-run перед реальным запуском.**
3. **Сохраняй лог** каждой операции.
4. **Unknown date → `unsorted/`**, никогда не терять файл.
